\section{Problem}

Overparameterized networks have many parameter settings with the same training loss, and the optimizer
decides which one training returns. In linear models each first-order method converges to the
max-margin solution of its own norm: $\ell_2$ for gradient descent \citep{soudry2018separable},
$\ell_\infty$ for Adam \citep{zhang2024adam} and the spectral norm for Muon
\citep{fan2025spectral}. For nonlinear networks the evidence is mixed: adaptive methods were found to
generalize worse \citep{wilson2017marginal}, while recent theory finds that Adam learns richer features
than gradient descent and can be more robust \citep{vasudeva2025rich}. We ask a causal question: \emph{at matched training loss, do SGD, Adam and Muon return functions of different
complexity, curvature and robustness, and does switching optimizer move the function toward the new
optimizer's typical solution?}

\section{What we plan to achieve}

\begin{enumerate}
\item \textbf{A model bank} of converged networks trained with SGD with momentum, AdamW and Muon, on an
image task (CIFAR-10) and a language task (TinyStories) at three model sizes, plus a linear sanity check.
\item \textbf{A large-scale function comparison} of these models through input-derivative metrics of first to
third order and a broad set of weight norms. The
norms test the linear-theory prediction that each optimizer keeps its own norm small, which is exact on
separable data, in nonlinear networks and across model sizes.
\item \textbf{A causal test by swapping.} If the optimizer selects the function, switching from $A$ to $B$
after convergence should move the metrics toward $B$'s values, unless $A$'s solution is stable under $B$.
We test all ordered pairs, with $B$'s optimizer state carried over in shadow to avoid a cold start.
\end{enumerate}

\section{How we plan to achieve it}

\subsection{Tasks}
 (0) Linearly separable synthetic data with a linear model, as a check against the known
limits. (A) A small GELU convolutional network on CIFAR-10. (B) A small GELU transformer language model on TinyStories, the setting Muon was designed for. Each task is run at three model sizes: input dimension for task 0, width for the CNN, roughly 1M, 3M and 10M parameters for the language model. The architecture is otherwise fixed within each task.

\subsection{Matched-loss model bank}
 At each model size, each optimizer is trained with three learning rates and three seeds (81 runs per task), and trained to convergence, i.e. until the training loss plateaus. We report the final training and test loss with every metric. Steps are recorded, as the function can drift at constant loss.

\subsection{Function metrics}

\paragraph{Input-derivative metrics.} At test points $x$, let $f$ be
the loss at the true label as a function of the input, $H(x)=\nabla^2 f(x)$, $\lambda(x)$ its largest eigenvalue
with unit eigenvector $v(x)$, and $T(x)=\nabla^3 f(x)$. For the language model, $x$ is the sequence of input embeddings and $f$ the next-token loss. Each of the metrics below measures how fast $f$, or one of its derivatives, varies with the input, so a simpler function should have smaller values and less spread across test points; we report the mean and the standard deviation over the test set.
\begin{itemize}
\item \emph{First order}: the Frobenius norm of the input Jacobian of the logits, a measure of sensitivity
linked to generalization and robustness \citep{novak2018sensitivity}.
\item \emph{Second order}: the Frobenius norm of $H$, estimated with Hutchinson's method from
Hessian-vector products, and $\lambda$, by power iteration, both linked to robustness by CURE \citep{moosavi2019cure}; and the curvature of the level sets of $f$, i.e.\ how fast the gradient direction turns, a projected variant of the normalized curvature of \citet{srinivas2022lowcurv}. With $\hat g=\nabla f/\|\nabla f\|$ and $P=I-\hat g\hat g^\top$, it is $\|PHP\|_F/\|\nabla f\|=\sqrt{\mathbb{E}_z\|PH(Pz)\|^2}/\|\nabla f\|$, estimated through random probes $z$ with identity covariance.
\item \emph{Third order} (novel, to the best of our knowledge): how the curvature changes between nearby
points. All three quantities use one primitive, $T[u,u,\cdot\,]=\nabla_x\big(u^\top H(x)u\big)$ with $u$ held fixed,
computed by differentiating a Hessian-vector product.
\begin{itemize}
\item \emph{Size of $T$}: its spectral norm $\|T\|_\sigma=\max_{\|u\|=1}|T[u,u,u]|$, estimated by the shifted tensor
power iteration $u\leftarrow (T[u,u,\cdot\,]+\alpha u)/\|T[u,u,\cdot\,]+\alpha u\|$ from a few random starts.
\item \emph{Third derivative along the sharpest direction}: $T[v,v,v]=\frac{d^3}{dt^3}f(x+tv)\big|_{t=0}$, with $v$
from the power iteration on $H$ and its sign fixed by $v^\top\nabla f\ge 0$.
\item \emph{Curvature length scale}: $\lambda/\|\nabla_x\lambda\|$, the distance over which, to first order,
the top curvature doubles or vanishes; small values mean the curvature varies sharply. For simple $\lambda$, $\nabla_x\lambda=T[v,v,\cdot\,]$.
\end{itemize}
\end{itemize}

\paragraph{Weight norms.} The $\ell_0$, $\ell_1$, $\ell_2$, $\ell_3$ and
$\ell_\infty$ norms of all weights; per layer, the spectral norm, the nuclear norm and the stable rank; and the path norm, the spectral complexity and the distance
from initialization, the last three among the generalization measures compared by \citet{jiang2020fantastic}.

\paragraph{Accuracy and robustness.} Test accuracy (next-token accuracy for the language model). For the image models, accuracy under Gaussian input noise; for the language model, the sensitivity of \citet{hahn2021sensitivity}, i.e.\ how often the prediction changes when a single input token is replaced.

\subsection{Swap intervention}
We run a swap for every ordered pair $(A,B)$ of distinct optimizers among SGD, AdamW and Muon, six in total. The swap happens after convergence \citep[cf.][]{keskar2017swats}: from the converged model of $A$, we continue training with $B$ until it converges again.
To avoid a cold start, $B$'s state is accumulated in shadow during
$A$'s run, from $A$'s gradients and without applying $B$'s updates, so no learning-rate re-warm is needed. The control is $A$ continued with $A$ for the same number of steps. The
effect of the swap is the change in each metric relative to this control, compared with the pure-$A$ to
pure-$B$ gap.

\subsection{Analysis}
 For each metric, the gap between optimizers in units of the seed-to-seed spread, and the
fraction of it a swap closes. A large fraction means the optimizer still shapes the function inside the basin; a small one, that the bias is set earlier.
