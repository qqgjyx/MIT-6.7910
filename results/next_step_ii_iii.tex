\paragraph{Summary.} (ii) asks whether each property that separates AdamW and Muon in Step 2 of the checkpoint
follows from Muon's update rule or emerges during training; (iii) asks whether these properties explain why Muon
trains faster. (1)~The Step 2 runs reproduce on a new cluster. (2)~Fed the same real gradients,
each optimizer's rule produces its own weight spectra and update similarity: these properties come from the rule
acting on gradients with low-rank structure, whichever optimizer produced them. (3)~Weight decay does not explain
Muon's speed; without orthogonalization Muon trains worse than AdamW. Whether the spectra cause the speed is still
open.

\paragraph{Setup.} TinyStories-10M with the checkpoint's settings (AdamW $2\cdot10^{-3}$, Muon 0.01, 10{,}000 steps,
data orders 0 to 2), on FAS RC Cannon (A100 MIG 3g.20gb slices). New runs are compared only with new runs; the
checkpoint's numbers serve only as a reproduction check.

\paragraph{1. Reproduction (Table~\ref{tab:repro}).} The rerun Step 2 runs match the checkpoint within the
spread over data orders, in final loss, in speed and in the Step 2 metrics. The other 26 rows of the checkpoint's
Table 3 also agree.

\paragraph{2. The rules without learning (Figure~\ref{fig:noise}).} \emph{Test.} We take one block matrix of each shape from
the initialization and update it with each optimizer's rule for 10{,}000 steps, with the runs' learning rates and
schedule, but feed it synthetic gradients instead of real ones: either i.i.d.\ Gaussian noise, or a fixed random rank-4
direction plus noise of the same Frobenius norm. Nothing is learned and the gradients do not depend on the weights.

\emph{Update similarity follows from the rule.} On pure noise, consecutive updates have cosine 0.90 under AdamW's
rule and 0.66 to 0.76 under Muon's, close to the real runs at training loss 1.81 (0.89 and 0.74). The gap needs no
signal at all, which agrees with the checkpoint's swaps, where this cosine changes as soon as the optimizer does.

\emph{The weight spectra do not follow from the rule alone.} On pure noise, neither rule changes the stable rank of
$W$ from its initial value. With the low-rank signal, both rules end near the signal's rank, but AdamW's rule gets
there within a few hundred steps and Muon's only by the end (stable rank at step 1000: 3.7 against 9.9). Muon sets
the update's singular values to about 1, so the noise directions move as much as the signal's and the spectrum stays
flat for longer; AdamW's elementwise update keeps the signal's low-rank structure (a sign of a rank-1 matrix is rank
1). So the rule shapes the spectrum only through the structure of the gradients it is fed.
